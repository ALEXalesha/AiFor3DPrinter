# AiForPrinter: ИИ следит за печатью

Отдельный проект, не игра. Алексей назвал его первым в очереди, это волна 1, см. `C:\Work\PythonAiGames\docs\queue.md`.

Задача: нейросеть смотрит на камеру принтера Elegoo Centauri Carbon и замечает брак:

- «спагетти»;
- деталь оторвалась от стола;
- пластик налипает комом на сопло;
- пластик не идёт, то есть печать идёт «в воздух».

Если что-то не так, бот n8n присылает в Telegram фото и кнопки «Пауза» и «Всё нормально».

## 2. Как устроено

```
AiForPrinter/
  watcher/        служба: раз в N секунд берёт снимок у camera_server, оценивает, решает
  model/          сеть, обучение, паспорт (точность, ложные тревоги)
  dataset/        инструменты: нарезка кадров из таймлапсов, разметка, аугментация
  ui/             окно PySide6: живой вид, тепловая карта «где брак», история, настройки
  tests/
```

### Служба

- Работает только во время печати. Статус берётся через `/status`.
- Снимок раз в 10-20 секунд, частота настраивается.
- **Решение по нескольким кадрам подряд.** Например, 3 из 4 кадров «брак» с уверенностью выше порога, а не один кадр. Так меньше ложных тревог.
- **Тревога:** бот n8n шлёт фото с отметкой, где брак, и кнопки «⏸ Пауза» и «✅ Всё нормально». «Всё нормально» записывает кадр как пример без брака для дообучения.
- **Автопауза - выключена по умолчанию.** Включается в настройках только после «да» Алексея, когда цифры ложных тревог станут хорошими.
- **Остановку печати (`/stopprint`) служба не вызывает никогда.** Это только человек.
- Служба не мешает камере и боту. Если `camera_server` не отвечает, она ждёт и пишет в журнал, а не падает.

### Сеть

- Задача - классификация кадра (норма, спагетти, отрыв, ком, нет пластика) плюс тепловая карта, где именно брак (Grad-CAM).
- Обучение на видеокарте, это вопрос Алексея из прошлых разговоров. Здесь PyTorch уместен, как в AiWorkbench: это не игра, размер сборки не так важен.
  - Взять небольшую предобученную сеть (MobileNet или EfficientNet-B0 с лицензией Apache или BSD) и дообучить.
  - Для службы - экспорт в ONNX и запуск через onnxruntime. Служба легче без torch.
- **Данные:**
  1. Свои кадры из таймлапсов и с камеры. Нормальных кадров много.
  2. Брак: открытые наборы с подходящей лицензией. Каждую лицензию записать в `dataset/LICENSES.md`; без лицензии или «только некоммерческое» - не брать.
  3. Свои искусственные примеры брака поверх нормальных кадров.
  4. Кадры, размеченные Алексеем кнопками в Telegram.
- **Чужие модели и код Obico (Spaghetti Detective, AGPL) не копировать.** Идеи брать можно.
- **Паспорт модели:**
  - точность и полнота по каждому виду брака;
  - **ложные тревоги на час нормальной печати** - главная цифра;
  - как быстро брак замечается после начала.

  Проверка - на кадрах печатей, которых не было в обучении.

### Окно

- Живой снимок и тепловая карта брака.
- Уверенность по видам брака, график за печать.
- История тревог с кадрами.
- Настройки: частота, порог, автопауза, Telegram вкл/выкл.
- Темы Paint, RU/EN, window-state. Тесты только offscreen.

## 3. Ограничения

- **Принтером управлять осторожно:** только пауза, только по кнопке человека. Автопауза - только после «да» Алексея. Никакой остановки печати.
- **Деплой бота:**
  - менять n8n только через `scripts\deploy-bot.js`;
  - перед этим тесты бота;
  - ожидание запуска n8n с тайм-аутом и проверкой, что процесс жив.
- Не публиковать кадры, по которым видно комнату и личные вещи. В репозиторий кладутся только обрезанные кадры стола или синтетика.
- Личное не публиковать. Удалять только в Корзину.
